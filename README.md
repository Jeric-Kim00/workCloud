## HUMAN · 자연스러운 한국어

**AI가 답변이나 문서를 작성할 때부터 읽기 편하고 사람이 쓴 듯 자연스러운 한국어로 완성하는 스킬입니다.** 원문이나 개인 글 샘플 없이 사용할 수 있고, 업무용·일상용 말투는 요청과 맥락에 맞춰 적용합니다.

```text
$human-korean 이 내용을 팀장에게 보고할 메일로 써줘: …
```

```text
$human-korean 데이터베이스 인덱스를 쉽게 설명해줘.
```
