# 도입 문의 새 행 메일 알림

대상 시트: 「타임리 AI 도입 문의 현황_2026_(타임리 AI 지원)」의 `도입 문의` 탭
받는 사람: `mhkim@timely.kr`
코드: [`inquiry-notifier.gs`](./inquiry-notifier.gs)

## 동작 방식

- 10분마다 시트를 확인해, **접수일·문의처·담당자**가 모두 채워진 행 중 아직 알리지 않은 행을 1건당 메일 1통으로 보냅니다.
- 입력 도중에 메일이 나가지 않도록, 직전 확인 때와 내용이 같아진 뒤에 보냅니다. 그래서 행을 추가한 뒤 **10~20분 안에** 메일이 도착합니다.
- 직접 입력, 복사·붙여넣기, Google Form 연동 모두 동작합니다. 행을 정렬하거나 순서를 바꿔도 다시 보내지 않습니다.
- 메일 내용: 접수일, 도입현황, 문의 형태, 문의처, 지역, 상세, 소속·직급, 담당자, 전화번호, 이메일, 상담 내용, 해당 행으로 바로 가는 링크

## 설치 (최초 1회, 약 3분)

1. 시트를 열고 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`의 내용을 모두 지우고 `inquiry-notifier.gs`의 내용을 붙여넣은 뒤 저장(💾)합니다.
3. 위쪽 함수 선택 목록에서 `setup`을 고르고 **실행**합니다.
   - 처음 실행하면 권한 승인 창이 뜹니다. 계정을 선택하고 **허용**을 누르세요. (스프레드시트 읽기, 메일 보내기, 트리거 실행 권한)
   - 이 단계에서 기존 행은 모두 '이미 알림'으로 처리되므로 메일이 가지 않습니다.
4. (선택) `sendTestMail`을 실행하면 마지막 문의 행으로 테스트 메일이 1통 갑니다.

> 메일은 **설치한 사람의 계정**에서 발송됩니다. 설치한 사람이 시트 편집 권한을 잃거나 퇴사하면 알림이 멈추니, 계속 시트를 관리할 계정으로 설치하세요.

## 변경 / 중지

- 받는 사람 변경: 코드 맨 위 `RECIPIENTS`를 수정합니다. 여러 명이면 `'a@timely.kr,b@timely.kr'`처럼 씁니다. 수정 후 저장만 하면 됩니다.
- 확인 주기 변경: `INTERVAL_MINUTES`(1, 5, 10, 15, 30 중 하나)를 수정한 뒤 `setup`을 다시 실행합니다.
- 알림 중지: `teardown`을 실행합니다.

## 알아둘 점

- 이미 알린 행의 **접수일·문의처·담당자**를 나중에 고치면 새 건으로 보고 메일을 한 번 더 보냅니다. 상담 내용이나 영업팀 확인 같은 다른 칸을 고치는 것은 상관없습니다.
- 헤더(1행)의 열 이름으로 위치를 찾으므로 열 순서를 바꿔도 괜찮습니다. 다만 `접수일`, `문의처`, `담당자` 등 열 이름을 바꾸면 코드의 `CONFIG`도 같이 바꿔야 합니다.
- Google Workspace 계정의 메일 발송 한도는 하루 1,500통이므로 이 용도에서는 문제가 되지 않습니다.
