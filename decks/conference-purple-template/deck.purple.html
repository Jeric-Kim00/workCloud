MATURITY 성숙도

도시 지능의 다섯 단계

Level 1(Driver Assistance)
파편화된 감지
CCTV·IoT 센서가 특정 현장의 데이터를 모니터에 표시하는 수준
Level 2현재 여기
(Partial Automation)
통합 관제
여러 출처를 한 화면에 모으지만 판단은 사람이 합니다
Level 3(Conditional Automation)
예측과 제안
이상을 먼저 감지하고 대응안을 제시하지만 승인은 사람이 합니다
Level 4(High Automation)
자율 실행
정해진 범위 안에서 판단과 실행을 스스로 마칩니다
Level 5(Full Autonomy)
완전 자율 지능
행정·교통·에너지가 하나의 Brain으로 연결돼 스스로 성장합니다
