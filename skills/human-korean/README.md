# HUMAN 1.0.1

AI가 답변이나 문서를 작성할 때부터 읽기 편하고 사람다운 한국어로 완성하는 스킬입니다. 원문이나 개인 글 샘플 없이 사용할 수 있습니다.

## 사용 예

스킬을 지원하는 환경에 등록한 뒤 작업 요청에 스킬을 지정합니다. Codex에서 스킬 이름을 직접 지정하는 요청 예시는 다음과 같습니다.

```text
$human-korean 이 내용을 팀장에게 보고할 메일로 써줘: …
```

```text
$human-korean 데이터베이스 인덱스를 처음 배우는 사람에게 설명해줘.
```

```text
$human-korean 오늘 이사 도와준 친구한테 고맙다고 짧게 써줘.
```

```text
$human-korean 이 보고서를 업무용 문체로 다듬어줘: …
```

업무용·일상용을 지정할 수 있고, 생략하면 요청의 맥락에 맞춥니다. 사용하는 도구의 스킬 선택 기능으로 지정해도 됩니다. 자동 호출 여부는 호스트에 따라 달라집니다.

## 파일 구성

- `SKILL.md`: 작성 원칙과 출력 전 점검. 핵심 기능은 이 파일만 읽어도 작동합니다.
- `references/modes.md`: 업무·일상·설명 등 상황별 조정.
- `references/examples.md`: 새 글 작성과 기존 글 윤문의 예시.
- `agents/openai.yaml`: Codex용 표시 이름과 기본 호출 문구.
- `RESEARCH.md`: 비교한 공개 자료와 설계 근거.
- `evals/review.md`: 경계 사례 검토와 검증 범위.
- `install.ps1` / `install.py`: Windows 및 Python 사용자 설치기.
- `tests/test_install.py`: 백업·복구·반복 설치 검사.

## 설치

설치는 현재 사용자에게 적용되므로 해당 PC의 모든 Codex 프로젝트에서 사용할 수 있습니다. 관리자 권한은 필요하지 않습니다. 다른 PC나 새 클라우드 환경에는 별도로 설치해야 합니다.

### Windows 개인 PC

배포 ZIP을 내려받아 압축을 푼 뒤, `human-korean` 폴더에서 PowerShell을 열고 실행합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

실행 정책 변경은 이 프로세스에만 적용됩니다. 시스템 정책은 변경하지 않습니다. 기본 설치 위치는 `%USERPROFILE%\.codex\skills\human-korean`이고 `CODEX_HOME`을 지정했다면 그 위치를 사용합니다. 기존 버전이 다르면 먼저 백업하며, 같으면 다시 복사하지 않습니다.

### 클라우드·Linux·macOS

압축을 푼 `human-korean` 폴더에서 실행합니다.

```bash
python3 install.py
```

기본 설치 위치는 `${CODEX_HOME:-$HOME/.codex}/skills/human-korean`입니다. 기존 파일은 비교한 뒤 필요할 때 백업하고 교체합니다. 설치를 마친 뒤 같은 환경의 새 Codex 세션에서 `$human-korean`을 지정하세요.

### GitHub에서 받기

저장소는 비공개이므로 접근 가능한 GitHub 계정으로 로그인해야 합니다. 이 변경이 main에 병합되기 전에는 설치 브랜치를 지정합니다.

```bash
gh repo clone Jeric-Kim00/workCloud workCloud-human -- --branch codex/add-human-korean
cd workCloud-human/skills/human-korean
```

그다음 위의 운영체제별 설치 명령을 실행합니다. 이미 같은 이름의 폴더가 있다면 다른 빈 경로에 내려받으세요.

스킬을 지원하지 않는 도구에서는 `SKILL.md`의 본문을 해당 작업의 작성 지침으로 사용할 수 있습니다. 파일을 받는 것만으로 계정 전체에 자동 설치되지는 않습니다.

## 기대하는 결과

상투적인 도입, 반복, 번역투, 과장과 과도한 압축을 줄입니다. 업무 문서는 명확하고 정중하게, 일상 글은 관계에 맞게 편안하게 작성합니다. 요청에 필요한 내용, 수치, 조건과 불확실성은 유지합니다.

모든 답변을 짧게 만들거나 모든 글을 캐주얼하게 만드는 설정은 아닙니다. 개인 말투 재현은 선택 기능이며 기본 사용에 필요하지 않습니다. 글을 생성할 때 외부 API나 실행 스크립트는 필요하지 않습니다. 포함된 설치기는 파일 배치에만 사용하며 실제 생성은 사용 중인 AI 모델이 수행합니다.

## 검증 상태

버전 1.0.1은 원문 없는 작성 중심으로 규칙을 정리하고, 형식·참조·패키지 구성을 검사한 사용 가능한 첫 버전입니다. 경계 사례는 작성자가 직접 검토했습니다. 별도 모델을 이용한 적용 전후 A/B 실험이나 사용자 선호 검증은 수행하지 않았습니다. 자세한 범위는 `evals/review.md`에 기록했습니다.

## 출처

공개 자료에서 얻은 설계 아이디어를 바탕으로 본문과 예시를 새로 작성했습니다. 외부 저장소의 코드나 실행 파일을 포함하지 않습니다. 비교 출처는 `RESEARCH.md`에서 확인할 수 있습니다. 설치기와 설치기 테스트도 직접 작성했습니다.
